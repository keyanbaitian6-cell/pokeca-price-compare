# 安全な運用ガイドライン＆関連法令チェック（必読）

本キットは、**「個人が自分の買い物・売却判断の参考にするために、ログイン不要の公開ページの価格情報を低頻度で整理する」** ことを前提に設計されています。  
対象サイトの運営者へ過度な負荷をかけたり、利用規約や法令に違反したりしないよう、以下のガイドラインを必ず守って運用してください。

---

## 1. 日本における関連 4 法令と安全な境界線（基礎知識）

Web 情報の自動取得自体は違法ではありませんが、やり方を誤ると以下の 4 つの法的・契約的リスクが生じます。本キットはこれらを踏まえて安全ガードを組み込んでいます。

| 関連する法律・ルール | リスクになる行為（NG） | 本キットの安全方針（OK） |
| --- | --- | --- |
| **① 著作権法（第 30 条の 4）** | 取得したテキスト・価格表・画像を外部サイトへ無断転載・再配布・DB販売する／情報解析用に販売されている有料DBを無断収集する | 自分専用の比較・情報解析のみに利用し、**Private リポジトリ＆自分専用シート** で管理。外部公開・再配布はしない |
| **② 不正アクセス禁止法** | ログインが必要な会員ページへ不正侵入する、認証壁・CAPTCHA を回避して取得する | **ログイン不要で誰でも見られる公開ページのみ** を対象とする |
| **③ 偽計業務妨害罪**（岡崎市立中央図書館事件の教訓） | 短時間に大量リクエストを連打し、相手サーバーの業務を妨害する | 最小 **1.5 秒以上の待機ガード（既定 2.0 秒）**・**完全直列アクセス**・**1サイト上限 20 ページ**・**1日1回程度** を強制 |
| **④ 民法上の利用規約違反** | 自動取得（スクレイピング・Bot）を禁止する利用規約や `robots.txt` を無視して取得する | 事前確認を必須とし、既定で **`respect_robots_txt: true`**（不許可URLを自動停止）を標準有効化 |

## 2. 本キットに組み込まれている技術的安全ガード

誤設定によって対象サイトへ迷惑をかけないよう、以下の制限をプログラム側で強制しています。

| 安全項目 | 初期値 | システム強制ガード | 推奨運用 |
| --- | --- | --- | --- |
| 1 リクエストごとの待機時間 | **2.0 秒** | **1.5 秒未満は起動拒否** | 2.0〜3.0 秒 |
| 1 サイトあたりの巡回ページ数 | **5 ページ** | **20 ページ超は起動拒否** | 1〜5 ページ |
| 同時アクセス数 | **1（直列のみ）** | 並列巡回機能なし | 順番に 1 ページずつ |
| `robots.txt` 自動確認 | **有効 (`true`)** | `Disallow` URL を検知し自動中止 | 必ず `true` のまま維持 |
| 自動更新の頻度 | **1 日 1 回** | 同時実行ロック (`concurrency`) | 1 日 1〜2 回まで |
| スマホ手動更新クールダウン | **5 分間** | **5 分未満には変更不可** | 必要なときだけ起動 |
| 秘密情報混入防止 | — | `config.json` に通知Webhook直書き不可 | 必ず GitHub Secrets で管理 |

## 3. インフラ利用規約の注意点（個人利用 vs 副業・商用利用）

- **GitHub Actions 無料枠**：非公開リポジトリでも月 2,000 Linux 分まで無料（1日1回・約1分の実行なら月約 30 分＝無料枠の 1.5% 程度）。
- **スマホ手動更新のインフラ規約に注意**：
  - **Vercel Hobby（無料枠）** は利用規約上 **「個人の趣味・非商用プロジェクト専用」** です。
  - 副業・せどり・買取事業・業務リサーチなど **営利目的** でスマホ手動更新を使う場合は、規約上商用利用が認められている **「GitHub 公式スマホアプリ直起動」** または **「Cloudflare Workers 無料枠（`mobile_updater/cloudflare_worker.js`）」** を選択してください。

## 4. サイト追加前の 30 秒セルフチェックリスト

新しいサイトを `config.json` に登録する前に、すべてチェックが付くことを確認してください。

- [ ] ログインなしで誰でも見られる公開ページである
- [ ] サイトの利用規約を確認し、自動取得を明確に禁止していない
- [ ] `https://ドメイン/robots.txt` を確認し、対象 URL が `Disallow` されていない
- [ ] 監視ページ数は 1 サイトあたり数ページ以内に絞っている
- [ ] `request_delay_seconds` は `2.0` 秒以上に設定している
- [ ] 取得データの用途は自分専用の閲覧・比較・分析のみである（転載・再配布しない）
- [ ] 秘密情報（サービスアカウント JSON・Webhook URL・トークン・合言葉）をコードや無料 AI チャットへ貼っていない
