# 安全な運用ガイドライン（必読）

本キットは、**「個人が自分の買い物・売却判断の参考にするために、公開ページの価格情報を低頻度で整理する」** ことを前提に設計されています。  
対象サイトの運営者へ過度な負荷をかけたり、利用規約や法令に違反したりしないよう、以下のガイドラインを必ず守って運用してください。

---

## 1. 必ず守るべき 5 つの大原則

### ① 「誰でも見られる公開ページ」だけを対象にする
- ログインが必要な会員専用ページ、マイページ、購入履歴ページ、課金コンテンツ、招待制サイトは対象にしないでください。
- 認証回避、Bot 対策（CAPTCHA 等）の突破、アクセス制限の迂回を行う改造は禁止します。

### ② 監視前に「利用規約」と `robots.txt` を確認する
新しいサイトを `config.json` に追加する前に、以下の 2 点を必ず確認してください。

1. **対象サイトの利用規約（Terms of Service）**
   - 「自動取得（スクレイピング・クローラー・Bot）の禁止」が明記されているサイトは対象から外してください。
2. **対象サイトの `robots.txt`**
   - ブラウザで `https://対象サイトのドメイン/robots.txt` を開くと、自動取得を拒否しているパス（`Disallow:`）を確認できます。
   - 本キットは既定で `"respect_robots_txt": true` となっており、`robots.txt` で禁止されている URL を検知すると自動で取得を中止します。**正当な理由なく `false` に変更しないでください。**

### ③ 取得間隔と実行頻度を「人間が手で見るより控えめ」に保つ
本キットには、誤設定で対象サイトに迷惑をかけないための **技術的ガードレール** を組み込んでいます。

| 安全項目 | 本キットの初期値 | 強制ガード（システム上限・下限） | 推奨運用 |
| --- | --- | --- | --- |
| 1 リクエストごとの待機時間 | **2.0 秒** | **最小 1.5 秒未満はエラーで起動拒否** | 2.0〜3.0 秒 |
| 1 サイトあたりの巡回ページ数 | **5 ページ** | **最大 20 ページ超はエラーで起動拒否** | 1〜5 ページ |
| 同時アクセス数 | **1（完全直列）** | 並列アクセス機能なし | 1 リクエストずつ順番に取得 |
| 自動更新の頻度（GitHub Actions） | **1 日 1 回** | — | 1 日 1〜2 回まで |
| スマホ手動更新の連続実行防止 | **5 分間ロック** | **最小 5 分未満は設定不可** | 必要なときだけ手動実行 |

> **禁止例**: cron を 5 分おきに書き換える、大量の URL（数百ページ）を一気に巡回させる、待機ガードのコードを削って高速連打する、といった使い方は絶対にしないでください。

### ④ 取得したデータは「自分専用の閲覧・判断」に留める
- 取得した価格情報・商品名・画像・文章をそのまま公開サイトへ転載したり、データベースとして第三者へ再配布・転売したりしないでください（著作権・データベース保護・不正競争防止法・各社規約に抵触する恐れがあります）。
- GitHub リポジトリは必ず **Private（非公開）** にしてください。
- 出力先の Google スプレッドシートも **「リンクを知っている全員に公開」にはせず、自分とサービスアカウントのみ** の共有に留めてください。

### ⑤ 秘密情報（認証JSON・トークン・合言葉）を絶対に外部へ漏らさない
- Google サービスアカウントの JSON ファイル、GitHub パーソナルアクセストークン（PAT）、スマホ更新用の合言葉は、**絶対にコードの中や GitHub リポジトリ内に保存しないでください**。
- これらは必ず **GitHub Actions Secrets** と **Vercel Environment Variables** だけに登録します。
- 無料生成 AI（ChatGPT / Gemini / Claude）にエラーや設定を相談する際も、**認証JSONの中身・トークン・合言葉・個人メールアドレスは絶対に貼り付けないでください**。

---

## 2. サイト追加前の 30 秒セルフチェックリスト

新しいサイトを `config.json` に登録する前に、すべてチェックが付くことを確認してください。

- [ ] ログインなしで誰でも見られる公開ページである
- [ ] サイトの利用規約を確認し、個人利用の自動取得を明確に禁止していない
- [ ] `https://ドメイン/robots.txt` を確認し、対象 URL が `Disallow` されていない
- [ ] 監視ページ数は 1 サイトあたり数ページ以内に絞っている
- [ ] `request_delay_seconds` は `2.0` 秒以上に設定している
- [ ] 取得データの用途は自分専用の価格チェック・比較のみである

---

## 3. 公開API・公式CSVがある場合はそちらを優先しよう

もし対象サイトが **公式の公開 CSV・公開 Google スプレッドシート・公式 RSS・Schema.org 構造化データ（JSON-LD）** を提供している場合は、HTML 全体を何度も巡回するよりもサーバー負荷が低く、壊れにくいため積極的に活用してください。  
本キットは `csv_feed` および `json_ld` 方式に標準対応しています。

- 対象サイトの仕様変更・アクセス制限・メンテナンス等により一時的または継続的に価格取得ができなくなった場合でも、制作者は一切の責任を負いかねます（構造変更時の復旧方法は [`docs/AI_CUSTOMIZE_PROMPTS.md`](AI_CUSTOMIZE_PROMPTS.md) の「5分復旧プロンプト」をご活用ください）。
