## ▼ ここから無料公開エリア ▼

### 「毎日サイトを巡回して価格を見比べる作業、そろそろ終わりにしませんか？」

欲しい家電やカメラの値下がり、限定スニーカーや推し活グッズの在庫、あるいは手持ちのレトロゲームやトレカの買取相場——。

気づけば毎日、複数のショップをブラウザのタブで何枚も開いて、
- 「昨日より安くなったっけ？」
- 「A店とB店、結局どっちが得なんだろう？」
- 「あ、気づいたら目標価格を下回っていたのに売り切れてた…」

そんな **地味だけど確実に時間とお金を奪われる巡回作業** を、**月額サーバー代 0 円・有料AI API課金 0 円** で完全自動化できる個人用キットを作りました。

### なぜ「月額 0 円」で毎日勝手に動くのか？

高額なレンタルサーバーも、月額制の監視SaaSも、OpenAI や Claude の有料 API キーも一切使いません。  
個人利用の **無料枠だけ** をきれいに組み合わせた構成です。

1. **自動取得エンジン：GitHub Actions（無料枠・月額 0 円）**
   - あなたのパソコンの電源を切っていても、毎日決まった時間にクラウドが自動で価格を集めます。
2. **閲覧＆推移ダッシュボード：Google スプレッドシート（無料）**
   - 見やすく自動整形された 7 つのタブへ書き出され、スマホでもPCでもいつでもチェックできます。
3. **スマホから即時手動更新：Vercel（任意・無料枠・月額 0 円）**
   - 「今すぐ最新価格を見たい！」というときだけ、合言葉を入れてスマホから 1 タップで更新できます。
4. **サイト追加＆改造：手元の無料版 ChatGPT / Gemini / Claude（API課金 0 円）**
   - **本キット最大の差別化特典「購入者向け・生成AIカスタマイズプロンプト集」** を同梱。コードを書けなくても、普段使っている無料AIのチャット欄にコピペするだけで、あなたが見たいサイト専用にカスタマイズできます。

（※ ここに、付属デモで作成した Google スプレッドシート「比較」「価格推移」「目標アラート」のスクリーンショットを 2〜3 枚挿入すると成約率が大きく上がります）

### 自動生成される Google スプレッドシート（全 7 タブ＋保管用アーカイブ）

毎日更新されるたびに、以下の見やすいダッシュボードが自動で出来上がります。

1. **サマリー**：最終更新日時、全取得件数、比較対象数、目標達成件数、スマホ手動更新リンク
2. **比較（2サイト以上）**：
   - **最安値（安く買うモード）** または **最高値（高く売るモード）** を自動判定
   - ベスト価格セルを **緑ハイライト**、差率5%以上を **赤太字**、差額が大きい商品を **金太字** で強調
   - 前回記録との **前回比（±円）** を色分け表示
3. **価格推移（30日ミニグラフ `SPARKLINE` つき）**：
   - 1商品1行の横型マトリクスで、直近30回分の値動きを **セル内折れ線グラフ** で一目で把握
   - 全期間の日次履歴は非表示アーカイブシートへ欠損なく自動保存
4. **目標アラート**：
   - あなたが設定した目標価格に到達した商品だけに **`🎯 目標達成`** バッジを表示
5. **単独掲載**：1サイトだけにある商品を分離して、比較表をスッキリ維持
6. **更新履歴**：いつ何件取得できたかを新しい順で自動記録
7. **全取得**：元の商品名・在庫状態・商品URLの原本確認用

### どんなジャンルに使えるの？

設定ファイル **`config.json` 1 つを書き換えるだけ** で、どんなジャンルにも対応できます（ジャンル別の設定ひな形も 4 種類同梱！）。

- **家電・PC・ガジェット**：「最安値モード」で欲しい型番の底値＆値下げタイミングを監視
- **中古カメラ・レトロゲーム**：「買取最高値モード」で売り時と一番高く売れる店を比較
- **スニーカー・推し活グッズ・フィギュア**：在庫切れキーワードを登録して値下げ＆再入荷をチェック
- **日用品・消耗品**：よく買う定番商品の公開ページをまとめて底値チェック
- **トレカBOX 等**：公開価格表の横断比較や日々の相場推移の記録

### よくある質問（FAQ）

**Q. 本当に毎月 0 円で動きますか？追加のAPI課金はありますか？**  
A. はい、月額 0 円です。GitHub Actions（個人無料枠 2,000 分/月に対し本キットは 1 日 1 回で月約 30〜60 分程度）、Google Sheets API、Vercel Hobby 枠の範囲で完結します。ChatGPT / Gemini / Claude の有料 API キーも一切使いません。

**Q. プログラミング経験ゼロでも導入できますか？**  
A. 初期設定は図解付きマニュアルの通りにクリック＆コピペで進められます（目安 45〜60 分）。まず最初の 3 分で外部通信なしのデモが動くので、手元で挙動を見てから設定できます。

**Q. どんなサイトでも必ず取得できますか？**  
A. いいえ。利用規約や `robots.txt` で自動取得が制限されているサイト、ログインが必要なサイト、強いBot対策や完全なJavaScript動的描画のみのサイトは対象外となります。まずは監視したい公開ページが「右クリック → ページのソースを表示」で価格文字が見えるか、あるいは `ld+json` を含むかをご確認いただくと確実です。
