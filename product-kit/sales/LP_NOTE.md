### なぜ「月額 0 円」で毎日勝手に動き、スマホに通知まで届くのか？

高額なレンタルサーバーも、月額制の監視SaaSも、OpenAI や Claude の有料 API キーも一切使いません。  
無料枠だけをきれいに組み合わせた構成です。

1. **自動取得エンジン：GitHub Actions（個人無料枠 月 2,000 分・月額 0 円）**
   - パソコンの電源を切っていても、毎日決まった時刻にクラウドが自動で価格を収集します（1日1回・約1分なので月消費は無料枠の約 1.5%）。
2. **閲覧＆推移ダッシュボード：Google スプレッドシート（無料）**
   - 自動整形された **7 タブ** へ毎日書き出され、スマホでも PC でも一目で比較できます。
3. **目標価格の無料スマホプッシュ通知（標準内蔵・月額 0 円）**
   - LINE Notify 終了（2025年3月）後の定番である **ntfy.sh（アカウント登録すら不要！）／Discord／Slack** に対応。あなたが決めた目標価格に達した日だけスマホへ自動通知します。
4. **スマホから即時手動更新（商用/副業利用も安心の 3 方式対応）**
   - ① **GitHub 公式スマホアプリ直起動（設定 0 分・商用 OK・推奨）**
   - ② **Cloudflare Workers 無料枠（1日10万req・商用 OK）**
   - ③ **Vercel Hobby（個人の趣味・非営利利用向け）**
5. **設定とサイト追加：同梱ビジュアルツール ＋ 手元の無料 ChatGPT / Gemini / Claude（API 課金 0 円）**
   - コードを一切書かなくても、同梱のオフラインツール **`config_builder.html`** と **「購入者向け・無料生成AIカスタマイズプロンプト集」** で自分の見たいサイト専用に仕立てられます。

### v2.0 で「非エンジニアの 3 大挫折ポイント」をすべて潰しました

一般的な自動化テンプレートは「買ったけど動かせずに積む」ケースが多いです。本キットでは挫折原因を 1 つずつ潰しました。

- **挫折ポイント①「PC に Python を入れるところで詰む」**
  - → **解決**：Python インストール不要の **「ブラウザ完結ルート」** に対応！GitHub 上から `run_mode=demo` を押すだけでクラウド動作し、スマホの GitHub アプリにも綺麗な Markdown 比較表が自動表示されます。
- **挫折ポイント②「JSON のカンマ 1 個ミスでエラーになる」**
  - → **解決**：ブラウザで開くだけで動くオフライン専用ツール **`tools/config_builder.html`** を同梱。フォーム入力で安全チェック済みの `config.json`・合言葉 SHA-256 ハッシュ・JST→UTC `cron`・AIプロンプトまでワンクリック生成できます。
- **挫折ポイント③「自分の見たいサイトに書き換えられない」**
  - → **解決**：最大の差別化特典 **「購入者向け・無料生成AIカスタマイズプロンプト集（全 8 テンプレート＋ジャンル別 5 レシピ）」** を同梱。ブラウザで右クリック→HTMLコピー→普段の無料 ChatGPT / Gemini / Claude に貼るだけでそのまま動く設定やコードが出てきます。

### 自動生成される Google スプレッドシート（全 7 タブ＋非表示アーカイブ）

1. **サマリー**：最終更新日時、全取得件数、比較対象数、目標達成件数、手動更新リンク
2. **比較（2サイト以上）**：最安値（安く買う）または最高値（高く売る）を自動判定。ベスト価格セルの **緑ハイライト**・差率 5% 以上の **赤太字**・高額差額の **金太字**・**前回比** の色分けまで自動整形
3. **価格推移（30日 `SPARKLINE` ミニグラフつき）**：1商品1行の横型表に折れ線ミニグラフを自動描画。全期間の生データは非表示シートへ欠損なく蓄積
4. **目標アラート**：設定した「買い時／売り時」に到達した商品だけに **`🎯 目標達成`** バッジを表示
5. **単独掲載**：1サイトのみの商品を分離して比較表をスッキリ維持
6. **更新履歴**：実行ログを新しい順（最大 365 件）で自動記録
7. **全取得**：原文商品名・在庫状態・URLの確認用

### どんなジャンルに使える？

- **家電・PC・ガジェット**（`lowest` モード）：欲しい型番の底値・値下げを自動通知
- **中古カメラ・レトロゲーム**（`highest` / `lowest` モード）：買取最高値比較＆美品の掘り出し物監視
- **スニーカー・推し活グッズ・フィギュア**：在庫切れキーワードを登録して値下げ＆再入荷チェック
- **日用品・消耗品**：リピート品の公開ページ底値ウォッチ
- **トレカ BOX 等**：公開価格表の横断比較＆日々の相場推移記録
