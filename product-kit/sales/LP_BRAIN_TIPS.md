### まだ「毎月課金の価格監視ツール」や「手作業のサイト巡回」を続けますか？

- 欲しい家電・中古カメラ・スニーカーの底値を毎日チェックしている
- レトロゲームやトレカの買取相場を複数店舗で見比べている
- 推し活グッズや限定品の値下げ・在庫復活を逃したくない

もしあなたがこれらを **毎日スマホやPCで手作業巡回** しているなら、年間で何十時間も失っています。  
かといって、月額 1,980〜4,980 円の監視ツールやサーバーを借り続けるのももったいない。

そこで、**一度セットアップすれば「月額サーバー代 0 円・有料AI API課金 0 円」で毎日勝手に動き続ける『自分専用・価格監視＆比較スプレッドシート自動構築キット』** を完成させました。

---

### このキットが他のテンプレートと決定的に違う「3 つの理由」

#### 理由①：完全「月額 0 円・API 課金ゼロ」設計
- 自動巡回：**GitHub Actions（無料枠）**
- 比較＆推移ダッシュボード：**Google スプレッドシート（無料）**
- スマホからの即時手動更新：**Vercel（任意・無料枠）**
- サイト追加・改造：**手元の無料版 ChatGPT / Gemini / Claude のWeb画面にコピペするだけ**（OpenAI API 等の従量課金は一切なし！）

#### 理由②：実運用から生まれた「本当に使える」7 タブ自動整形シート
ただ CSV を吐くだけのスクリプトではありません。実際の価格比較運用で何度も改善を重ねた **見やすさ特化のスプレッドシート** を毎回自動生成します。
- **`比較` タブ**：2サイト以上ある商品だけを自動抽出し、最安値（または買取最高値）のセルを **緑ハイライト**。差率・差額・前回比も一目で分かります。
- **`価格推移` タブ**：1商品1行の横型表に **30日間のセル内ミニグラフ（`SPARKLINE`）** を自動描画。全期間の生データは非表示シートにずっと蓄積されます。
- **`目標アラート` タブ**：あなたが設定した「この値段なら買う／売る」に達した商品だけに **`🎯 目標達成`** バッジが点灯します。
- **`単独掲載` / `更新履歴` / `全取得` / `サマリー`** もすべて自動整理。

#### 理由③：非エンジニアでも挫折しない「無料生成AIカスタマイズプロンプト集」を同梱
テンプレート販売で一番多い悩みは **「自分の見たいサイトへの書き換えが分からない」** こと。  
本キットでは、ブラウザの「右クリック → HTMLコピー」で取った部品を **手元の無料 ChatGPT / Gemini / Claude に貼るだけで、そのまま動く設定やコードが出てくる 8 種の専用プロンプト集** を標準特典として同梱しています。

1. 公開ページのHTML → `config.json` 自動生成プロンプト
2. 複雑なサイト専用 `custom_collectors/*.py` 自動生成プロンプト
3. 複数店舗の「商品名表記揺れ」名寄せルール一括生成プロンプト
4. スプレッドシート列追加（送料・ポイント・利益計算等）カスタマイズプロンプト
5. 英語エラー丸投げ「一発デバッグ」プロンプト
6. 無料 Discord / Slack Webhook 目標価格プッシュ通知追加プロンプト
7. 蓄積データの「今週の買い時・売り時分析レポート」作成プロンプト
8. サイト構造変更で 0 件になったときの「5分復旧」プロンプト

### 先にお伝えする注意点（誠実な運用のために）

- **対象は「ログイン不要の公開ページ」のみ**です。会員専用ページ・認証突破・CAPTCHA回避・利用規約や `robots.txt` で自動取得が禁止されているサイトには使えません。
- 相手サーバーへ負荷をかけないよう、プログラム側で **1.5 秒以上の待機ガード**・巡回ページ上限・完全直列アクセス・5分クールダウンを強制しています。
- 初期設定（約45〜60分）には Windows または Mac のパソコンが必要です（設定後のチェックと手動更新はスマホだけでOK）。
