## 商品概要

家電・スニーカー・中古カメラ・レトロゲーム・推し活グッズ・トレカなど、**あなたがチェックしたい複数の公開Webページの価格を毎日自動取得し、見やすい Google スプレッドシートへ自動整形して比較できる個人用テンプレートキット** です。

- **月額サーバー代 0 円**（GitHub Actions 無料枠 ＋ Google Sheets ＋ 任意で Vercel 無料枠）
- **生成AI API 課金 0 円**（OpenAI / Claude / Gemini の有料APIキーは一切不要）
- **設定は `config.json` 1ファイル完結**（ジャンル別の設定ひな形 4 種類同梱）
- **「安く買う（最安値比較）」＆「高く売る（買取最高値比較）」両モード搭載**
- **購入者特典「無料生成AIカスタマイズプロンプト集」同梱**（普段の無料 ChatGPT / Gemini / Claude にコピペするだけで、自分の見たいサイト用の設定やコードが作れます）

## こんなことができます

1. **複数サイトの横断価格比較（2サイト以上を自動抽出）**
   - 最安値／最高値の自動判定、ベスト価格セルの緑ハイライト、差率・差額の強調表示、前回比の色分け表示。
2. **30日間の価格推移マトリクス＋ミニグラフ（`SPARKLINE`）**
   - 1商品1行で値動きを一望。全期間の過去履歴は非表示アーカイブシートへ欠損なく蓄積します。
3. **目標価格アラート（買い時・売り時自動判定）**
   - 「◯円以下になったら買い」「◯円以上になったら売り」を `config.json` に登録すると、到達した商品だけを「目標アラート」タブでハイライト表示します。
4. **スマホから合言葉で即時手動更新（任意・Vercel無料枠）**
   - Google Apps Script を使わないため未確認アプリ警告が出ず、合言葉の SHA-256 認証＋5分クールダウンで安全に運用できます。
5. **外部通信ゼロで3分で動かせるオフラインデモ同梱**
   - 解凍してすぐサンプルページで全機能を体験できます。
