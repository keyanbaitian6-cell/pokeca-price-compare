## 1. 段階値上げ（価格ラダー）設計：1,980円 → 4,980円

note 公式の約 30 万件有料記事分析（2026 年 1 月公開）では、**「テクノロジー・AI 活用」カテゴリが前年比 +268.6%** で急成長しており、実用ノウハウ系の売れ筋平均単価は **1,842 円** と報告されています。

## 3. 公開ライブデモ（`site/price-kit/`）を使った高転換ファネル

note 公式分析で判明した **「売れる実用記事は無料エリアが 1.5 倍厚く、購入前に価値を体感させている」** 事実に基づき、本プロジェクトでは **購入前にスマホでも触れる公開ライブデモページ** を用意しています。

```text
[X 告知スレッド / 無料記事 / 既存「トレカ損益ラボ」]
            │
            ▼
[公開ライブ体験LP：https://keyanbaitian6-cell.github.io/pokeca-price-compare/price-kit/]
 ・4ジャンル切替の7タブシート体験（目標価格スライダー→スマホ通知プレビュー）
 ・月額0円シミュレーション＆config.jsonプレビューで「非エンジニアでも使える！」を実感
            │
            ├──▶ [デジタル商品本体購入] note / BOOTH / Brain / Tips（1,980〜4,980円）
            │            │
            │            ▼
            └──▶ [個別カスタマイズ導線（バックエンド収益化）]
                 ① config.json 設定作成ライト代行（4,980円 / 最大3サイト）
                 ② 丸ごと初期構築伴走サポート（9,800〜14,800円）
                 ③ 独自機能・利益計算シート追加（6,800〜12,000円）
```

> **URL を完全に中立化したい場合**：`site/price-kit/` を Cloudflare Pages（無料・商用利用 OK）へ別プロジェクトとして接続すると、`https://price-monitor-kit.pages.dev` のような専用ブランド URL を月額 0 円で持てます。
