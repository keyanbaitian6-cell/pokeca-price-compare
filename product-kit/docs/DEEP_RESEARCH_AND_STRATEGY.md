### ③ 特定商取引法（特商法）と個人の住所非公開（2026 年検証済み）
- **note 公式ヘルプ確認**：反復継続販売で「販売業者」に該当する場合でも、**「請求があった場合に遅滞なく開示する旨」を記載すれば、住所・電話番号の常時掲載は省略可能**。note 経由の開示請求は運営宛の所定書類手続きが必要で、無断開示されない仕組みがある。
- **BOOTH 公式ヘルプ確認**：「販売業者」該当時は特商法表記が必要。自宅公開を避ける場合はプラットフォームルール確認のうえバーチャルオフィス等を検討。
- **再構築への反映**：`sales/PRICING_AND_FUNNEL.md` に正確な手数料シミュレーションと特商法確認チェックリストを明記。

### ④ Vercel Hobby 規約の落とし穴 vs 商用 OK 無料代替（重大発見！）
- **Vercel Hobby（無料）の最新利用規約**：厳格に **「個人の趣味・非商用プロジェクト専用」**。副業・せどり・買取リサーチなど営利目的での利用は規約違反リスクがある。
- **商用・副業利用も完全 OK な無料代替**：
  1. **GitHub 公式スマホアプリ（GitHub Mobile）またはブラウザの `Actions → Run workflow`**：追加アカウント 0 個・PAT不要・商用 OK・設定時間 0 分！さらに `workflow_dispatch.inputs` と `$GITHUB_STEP_SUMMARY` を使えば、スマホアプリから「本番／デモ／設定確認／通知テスト」を1タップ切替し、結果の比較表もアプリ上でそのまま見られる！
  2. **Cloudflare Workers 無料枠**：**1 日 10 万リクエスト無料・規約上商用利用 OK**！
  3. **Vercel Hobby**：純粋な個人・非営利利用の選択肢として明記。
- **再構築への反映**：v2.0.0 では **GitHub Mobile 直起動（推奨）＋ Cloudflare Workers（商用 OK）＋ Vercel Hobby（個人非営利限定）** の 3 方式に対応し、`mobile_updater/cloudflare_worker.js` を新規実装＆自動テスト済み！

### ⑤ LINE Notify 終了（2025/3/31）後の無料スマホ通知の標準化
- LINE Notify 完全終了後、2026 年の個人向け無料プッシュ通知の 3 大定番は **ntfy.sh（アカウント登録すら不要！）**・**Discord Webhook**・**Slack Webhook**。
- **再構築への反映**：v1.0.0 では「AIプロンプトで後から追加」だった無料通知を、v2.0.0 では **標準モジュール `src/price_monitor/notifier.py` として完全内蔵**！目標価格達成時だけスマホへ自動通知（有料API課金 0 円）。

### ⑥ 非エンジニア最大の離脱ポイント「Python インストール＆JSON 手編集の壁」の突破
- v1.0.0 は「PC に Python を入れて `venv` 作成」が最初のハードルになっていた。
- **再構築への反映**：
  1. **オフライン完結ビジュアル設定ツール `tools/config_builder.html`** を同梱（PC・スマホ両対応：`config.json` 作成／ブラウザ内 SHA-256 ハッシュ生成／JST→UTC cron計算／無料AIプロンプト自動組立）。
  2. **Python インストール不要の「ブラウザ＆スマホ完結ルート（ルート A）」** を `SETUP_GUIDE.md` のメイン導線に格上げ（GitHub Actions の `run_mode=demo` でクラウド上お試し完結！）。

### ⑦ 日本のスクレイピング 4 法令の明確化（コンプライアンス強化）
1. **著作権法第 30 条の 4**：情報解析目的の権利制限（ただし販売DB等、著作権者の利益を不当に害する場合を除く／取得データの転載・再配布は禁止）
2. **不正アクセス禁止法**：ログイン認証・ID/PW 突破の禁止（公開ページ限定）
3. **偽計業務妨害罪（岡崎市立中央図書館事件の教訓）**：高頻度アクセスによるサーバー負荷の禁止（本キットは最小 1.5 秒ガード・直列実行・上限 20 ページ・1日1回を強制）
4. **民法上の利用規約違反**：自動取得禁止規約・`robots.txt` 不許可ページは監視対象外とする

## 3. 【重要】公開リポジトリに関する収益防衛アドバイス

現在、本リポジトリ `keyanbaitian6-cell/pokeca-price-compare` は **`PUBLIC`（公開）** 設定です。

- **公開デモページ（`site/price-kit/`）** は集客・転換率アップのため **公開（PUBLIC）が最適** です。
- 一方で、有料商品の中身（`product-kit/template/`）まで同じ公開リポジトリに置き続けると、GitHub URL を知っている人が無料で閲覧できてしまいます。
- **おすすめ運用（本格販売開始時）**：
  1. 公開デモ（`site/price-kit/`）はそのまま GitHub Pages（または Cloudflare Pages の中立URL）で公開維持する。
  2. 有料ZIP販売を本格開始するタイミングで、有料商品テンプレート本体だけ **別の Private（非公開）リポジトリ** へ移すか、公開リポジトリ側は「無料体験 Lite 版（デモ専用）」・有料販売 ZIP を「完全版（Pro）」として差別化すると、セキュリティと収益性の両方を完璧に守れます。
