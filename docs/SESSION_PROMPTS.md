このリポジトリ（pokeca-price-compare）を使って、「案2：既存のポケカ価格自動取得パイプラインを拡張し、APIキー課金ゼロで生成AIと連携してX・noteで収益化する仕組み」を練り上げて完成まで実装してください。

- 楽天ROOMアフィリエイトは除外すること（note有料記事/メンバーシップ、X→トレカ買取・オリパ等ASPアフィリエイト、および同リポジトリ内 site/ の無料計算ツールへの送客で収益化する）

- docs/DECISIONS.md の前提を守り、特定店舗（runto・買取ソムリエ等）の価格表生データをそのまま丸転載・有料販売せず、市場トレンド・値動き傾向・考察の素材として安全に加工すること

【やってほしいこと】

   - 相場全体の地合いサマリー（上昇銘柄数 vs 下落銘柄数）

4. ユニットテスト（pytest）を追加して全テストが通ることを確認し、運用手順書（X/note収益化ロードマップ・投稿ルーティン）も作成する

まずリポジトリ構成と src/card_price_compare/・docs/DECISIONS.md を確認してから設計・実装を進めてください。

## 案3用プロンプト：「月額0円・自動価格監視シート構築キット」デジタル商品化（BOOTH / note / Brain 販売）

```text
このリポジトリ（pokeca-price-compare）の仕組みをベースに、「案3：月額サーバー代0円で動く『自分専用・価格監視＆比較スプレッドシート自動構築キット』をデジタル商品（note / BOOTH / Brain / Tips）として販売できる状態」まで練り上げて完成させてください。

【厳守条件】
- 生成AIを活用すること
- APIキーなど課金するもの（OpenAI/Claude/Gemini API等）を使う方法は除外すること
- 楽天ROOMアフィリエイトは除外すること（デジタル商品本体販売 1,980〜4,980円 ＋ カスタマイズ導線で収益化）
- 既存のポケカ運用コード（src/card_price_compare/, vercel/, .github/workflows/manual-update.yml）および完成済みの Webツール集（site/, .github/workflows/deploy-pages.yml）は壊さず、新しい専用ディレクトリ（例：product-kit/）に独立させて構築すること
- 特定店舗への過度なスクレイピング負荷や規約違反を助長しないよう、購入者向けの安全な運用ガイドライン（取得間隔・公開ページ前提・利用規約確認）を明記すること

【やってほしいこと】
1. 商品本体の「汎用テンプレートパッケージ（product-kit/template/）」を作成：
   - ポケカに限らず、家電・スニーカー・レトロゲーム・中古カメラ・推し活グッズなど任意の公開ページを監視できるように抽象化したシンプルな Python＋GitHub Actions＋Googleスプレッドシート自動出力＋スマホ手動更新テンプレート
   - 非エンジニアでも設定を1ファイル（config.json）で完結できる構成＋動作確認済みサンプル＆テスト
   - 配布用ZIPを1コマンドで生成できるパッケージングスクリプト
2. 商品価値を最大化する最大の差別化特典「購入者向け・生成AIカスタマイズプロンプト集」を作成：
   - 購入者がコードを書けなくても、手元の無料ChatGPT/Gemini/ClaudeにHTMLやURL構造の情報を貼るだけで「自分の見たいサイト用の取得スクリプト」「スプレッドシート列のカスタマイズ」「エラー解決」ができる実用プロンプト集
3. 非エンジニア向け「図解付き導入マニュアル（SETUP_GUIDE.md）」と「よくあるエラー解決集」を作成
4. 販売用LPテキスト（note / BOOTH / Brain それぞれにそのまま貼れるセールス文章・目次・価格設計・無料部分と有料部分の区切り設計・告知用Xスレッド原稿）を作成
5. テンプレートのテストがすべて通ることと、配布ZIPに秘密情報や不要ファイルが混入しないことを検証する

まず既存リポジトリの README.md・MANUAL_UPDATE_SETUP.md・docs/DECISIONS.md・src/・vercel/ の構成を確認してから、商品設計と実装を進めてください。
```
