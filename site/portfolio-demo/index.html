      本当に商用利用でも月額サーバー代0円で使い続けられますか？

      はい。自動実行に使うGitHub Actionsは非公開リポジトリでも月2,000 Linux分まで無料で、1日1回・約2〜3分の更新なら月約70〜90分（無料枠の5%未満）で収まります。Google Sheets APIも無料（1分あたり300リクエスト・日次上限なし）で、batch_update 集約により1実行約20コール程度です。さらにスマホ手動更新ページには商用利用が公式に許可されているCloudflare Pages / Workers無料枠（1日10万リクエスト無料）を採用しています（個人・非商用用途ならVercel Hobby等も選択可）。

      プログラミングやGitHubを触ったことがなくても大丈夫ですか？

      普段の業務で見るのはGoogleスプレッドシートだけなので、コードに触れる必要はありません。初回セットアップ（Googleシートの共有やシークレット登録）も、画面手順書またはチャット案内で迷わず完了できるようサポートします。

      対象サイトのデザイン変更で取得できなくなったらどうなりますか？

      HTML構造の変化で取得件数が0件になった場合、既存のスプレッドシートを空データで上書きしない保護機能（strictガード）を標準搭載しています。また、構造変更時のスポット修正（¥5,000〜¥10,000目安）や任意の月額ライト保守にも対応可能です。

      Google Apps Script（GAS）やIMPORTXMLで作る場合と何が違いますか？

      IMPORTXMLは件数が増えると「#N/A」や読み込み失敗が頻発し、GASには「1回の実行が最大6分で強制終了する」「JavaScript描画サイトを取れない」「初回にGoogleの未確認アプリ警告が出る」という弱点があります。GitHub Actions＋Python構成ならこれらの制約がなく、名寄せ・大量ページ巡回・高速な書式一括整形まで安定して動かせます。

      GitHub Actionsは60日間リポジトリ更新がないと定期実行が止まるって本当ですか？

      公開（Public）リポジトリでは60日間コミット等の活動がないとスケジュール実行が自動停止する仕様があります。本サービスでは原則お客様専用の非公開（Private）リポジトリで運用するほか、万一停止した場合のワンクリック再開手順やエラー通知設計もマニュアルに明記しているため安心です。

      Webスクレイピングは法律や規約面で問題ありませんか？

      ログイン不要の公開情報であっても、利用規約やアクセス頻度によってはトラブルになり得ます。そのため契約前に必ず「利用規約・robots.txt」「1秒以上の間隔制御」「非ログイン・個人情報非取得」「比較解析用途限定（著作権法30条の4への配慮）」の4基準を無料審査し、安全に運用できる対象のみを構築します。

      スマホから好きなタイミングで更新できますか？

      はい（オプション／カスタムプラン）。合言葉認証付きの専用更新ページをCloudflare無料枠で設置できるため、外出先や仕入れの現場からスマホで1タップするだけで数分後に最新データへ更新できます。
