WHY THIS KIT WORKS FOR NON-ENGINEERS

非エンジニアが「挫折せずに一生月額 0 円で回せる」6 つの設計

実運用でつまずきやすい「Python 導入・JSON 手編集・LINE Notify 終了・インフラ規約・サイト変更」を、v2.0 で最初からすべて解決しました。

01 / ZERO PYTHON SETUP

Python 不要・ブラウザ完結ルート対応

GitHub ブラウザ画面と Actions の run_mode=demo を使うことで、PC に Python を入れずにクラウド上だけで即テスト＆運用開始できます（PC ローカル3分デモも両対応）。

02 / OFFLINE STUDIO INCLUDED

ビジュアル設定ビルダー同梱

同梱の tools/config_builder.html をブラウザで開くだけ。フォーム入力でカンマミスゼロの config.json・SHA-256 ハッシュ・JST→UTC cron・AIプロンプトを1クリック生成。

03 / FREE PUSH ALERTS

ntfy.sh / Discord / Slack 通知を標準内蔵

終了した LINE Notify の代わりに、アカウント登録不要の ntfy.sh や Discord / Slack へ目標達成日・エラー発生時だけ無料プッシュ通知。GitHub スマホアプリのサマリー表も自動出力。

04 / FREE AI PROMPTS

無料生成 AI カスタマイズプロンプト集

有料 API キー不要。ブラウザの「右クリック→HTMLコピー」を普段の無料 ChatGPT / Gemini / Claude に貼るだけで、任意サイト対応・名寄せ・列追加・エラー復旧ができる 8 本のプロンプト集を同梱。

05 / 5 PARSER MODES

5 方式の取得エンジン（JSON-LD 優先）

HTML 一覧・個別ページ・壊れにくい Schema.org JSON-LD・公開 CSV・AI 生成カスタムプラグインの 5 方式を config.json で自在に切替可能。

06 / COMMERCIAL-SAFE MOBILE

商用/副業も安心なスマホ手動更新 3 方式

①GitHub 公式スマホアプリ直起動（0分・商用OK）②Cloudflare Workers 無料枠（1日10万req・商用OK）③Vercel Hobby（個人非営利向け）の 3 方式を規約どおりに使い分けできます。

FAQ

        
よくある質問

        

          

            本当に毎月 0 円で動き続けますか？AI の API キー課金は不要ですか？
            
はい、月額 0 円・API 課金ゼロです。GitHub Actions（非公開でも月 2,000 分無料・本キットは月約 30 分消費）、Google Sheets API、ntfy.sh / Discord、Cloudflare Workers の無料枠の範囲で完結します。カスタマイズも普段使っている無料版 ChatGPT / Gemini / Claude のチャット画面へコピペするだけです。

          

          

            PC に Python をインストールしたことがなくても導入できますか？
            
はい。v2.0 では同梱の tools/config_builder.html（ブラウザで開くだけ）と GitHub のブラウザ画面・Actions の demo モードを使う「Python 不要ルート」を用意しています。

          

          

            せどりや副業リサーチ（商用利用）でもインフラ規約は大丈夫ですか？
            
Vercel Hobby は「個人の趣味・非商用限定」のため、副業・商用利用では規約上商用利用が可能な「GitHub 公式スマホアプリ直起動」または同梱の「Cloudflare Workers 無料枠版」を使用する手順をマニュアルに明記しています。

          

          

            どんなサイトでも必ず価格を取得できますか？
            
いいえ。ログイン必須ページ、強い Bot 対策（CAPTCHA 等）、利用規約や robots.txt で自動取得が禁止されているサイト、完全な JavaScript 動的描画のみで構造化データもないページは対象外となります。
