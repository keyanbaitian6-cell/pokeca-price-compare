# 生成AIプロンプト集（提案〜設計・実装・テスト・マニュアル・保守まで全8本）

普段使っている生成AI（ChatGPT / Gemini / Claude のWeb画面またはIDEチャット）にそのまま貼り付けて穴埋めするだけで、受注〜納品までの実働を1/5に短縮できます。
**※外部の有料AI APIキーは一切不要です。秘密情報（認証JSON・合言葉・個人シートID）は絶対に貼り付けないでください。**

## Prompt #5：列仕様→「Googleスプレッドシート自動整形（batch_update＋30日推移）」生成

**用途**：`gspread`＋Sheets API `batch_update` で見栄え・APIコール数・安全性を両立した出力コードを生成

```text
Python 3.12＋gspread を使用し、Pandas DataFrame をGoogleスプレッドシートへ自動整形出力する `google_output.py` を作成してください。

【出力タブ仕様】
1. サマリー：最終更新日時、全取得件数、比較件数、エラー件数を `INDEX/MATCH/MAX` 数式で「更新履歴」タブから自動参照。書き込むセル範囲は `A1` と `A3:B8` のみに固定し、9行目以下のお客様手入力領域は絶対に上書きしない。
2. 比較（2サイト以上）：列＝{{例：商品名 / 状態 / 最安値 / 前回比 / 最安店 / 差率 / 差額 / ストアA / ストアB / ストアC / 注意}}
   - 並び順：差率の降順
   - 書式：濃紺ヘッダー（#1F3864・白太字）、ゼブラ配色（#F7F9FC）、最有利価格セル緑（#C6EFCE）、差率5%以上赤太字（#C00000）、差額3,000円以上金太字（#BF8F00）、前回比上昇緑/下落青、ヘッダーにセル注釈（note）付与。
3. 30日価格推移：1商品1行の横型マトリクス＋セル内 `=SPARKLINE(...)` ミニグラフ。全期間の日次生データは非表示シート「推移データ（保管用）」へ蓄積する2層構成。
4. 単独掲載：1サイトのみ掲載の行を分離表示。
5. 更新履歴：新しい順（最新が2行目）で最大365件保持。
6. 全取得：生データと元URLの監査用タブ。

【必須制約】

- `worksheet.clear()` は書式を残すため、毎回フォーマットをリセットしてから当て直す。
- 参照専用のスプレッドシートIDが誤って出力先に指定された場合は例外で拒否するガードを入れる。
```
